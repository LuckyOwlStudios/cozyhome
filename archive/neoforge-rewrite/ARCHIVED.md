# Archived: NeoForge-only rewrite

This folder is the previous `master` of this repository (a NeoForge-only rewrite using
Mojang mappings and DeferredRegister). It is **not built** anymore; the mod is now the
multiloader project at the repository root (`common/`, `fabric/`, `neoforge/`).

It is kept so its newer content (planked walls, railings, short tables, banner patterns,
the reworked counters and cushions) can be ported into the multiloader project.
